Recommended Initial Website Pages:

1. Home Page
- Main conversion landing page
- Hero section
- Experience preview
- Promo package preview
- Booking CTA
- Announcement section showing the latest blog/news post
- FAQ preview
- Footer

2. Promos / Packages Page
- Family Package: 3–6 pax
- Barkadahan Package: 7–10 pax
- Team Building Package: 10+ pax
- Package comparison
- Booking CTA

3. Booking Page
- Booking form
- Package selection
- Preferred schedule
- Customer contact details
- Notes/reminders

4. About / Experience Page
- Off-road go-kart concept
- Family bonding positioning
- Barkada challenge positioning
- Safety-focused explanation

5. Events Page
- Coming Soon page
- Future events, races, tournaments, private bookings, and team activities
- Email/Facebook follow CTA

6. Blog / News Page
- List of updates, announcements, promos, race news, safety tips, and local event posts

7. Single Blog / News Post Page
- Individual article/news layout
- Title, date, featured image, content, CTA

8. Contact / Location Page
- Location map
- Contact details
- Facebook page link
- Opening hours
- Inquiry CTA

Add an Announcement section on the homepage that automatically displays the latest blog or news post.

The section should include:
- Section label: Latest Announcement
- Blog/news title
- Short excerpt
- Publish date
- Featured image if available
- CTA button: Read More

Place this section after the promo/package preview or before the FAQ section.
