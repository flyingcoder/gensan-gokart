COLOR SYSTEM RULE:

Use a GenSan GoKart visual style that harmonizes with the provided brand images.

The main website colors must be red, orange, yellow, dark brown/black, white, and warm cream.

Use red tones as the primary background color to match the racing poster style.
Use orange and yellow as brand highlight colors for energy, speed, dirt, and excitement.
Use dark brown/black for outlines, shadows, text contrast, and rugged racing elements.
Use white and warm cream for readable content areas and clean spacing.

Use blue only as the action/conversion accent color.

Blue must be used for clickable or action-based elements only, such as:
- buttons
- links
- call-to-action text
- form submit buttons
- phone number links
- booking links
- map links
- “Book Now”
- “Reserve Your Slot”
- “Call Now”
- “View Packages”
- “Send Inquiry”

Do not use blue as a main background color or decorative brand color.
Blue should signal to users that an element is clickable or important.
